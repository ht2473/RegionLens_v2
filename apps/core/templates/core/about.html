{% translate "О проекте" %}

{% blocktranslate trimmed %} RegionLens — анализ и визуализация социально-экономических показателей регионов России: понятный ответ о регионе или показателе, а за ним — карта, рейтинги, инструменты анализа и выгрузка. {% endblocktranslate %}

{% translate "Зачем" %}

{% blocktranslate trimmed %} Статистика по регионам России выходит в разных изданиях Росстата, Банка России и ФНС России. Работать с ней напрямую тяжело: пропуски закодированы числами, методика наблюдения менялась, а значения за один и тот же год различаются между выпусками. {% endblocktranslate %}

{% blocktranslate trimmed %} RegionLens приводит наблюдения к единому виду, отмечает разрывы сопоставимости и пересмотры и считает меры сравнительного анализа; каждый расчёт описан в методике. {% endblocktranslate %}

{% blocktranslate trimmed %} Сайт работает на последней версии набора; новые версии загружаются по мере выхода. Ряды, которые Росстат публикует ежемесячно, продолжаются после последнего года набора по его бюллетеню и таблице ВРП, а ипотека, кредиты и малый бизнес — по данным Банка России и ФНС; сайт собирает их выпуски сам. {% endblocktranslate %}
