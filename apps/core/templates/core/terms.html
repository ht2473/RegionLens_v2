5. {% translate "Учётная запись" %}

  • {% blocktranslate trimmed %} Учётная запись нужна, чтобы сохранять регионы, показатели и виды экрана и видеть свои обращения. При регистрации указываются адрес почты, имя и пароль. {% endblocktranslate %}
  • {% blocktranslate trimmed %} Пароль хранится только в виде хэша. Вход с одноразовым кодом включается в разделе «Безопасность»; для панели управления он обязателен. {% endblocktranslate %}
  • {% blocktranslate trimmed %} Пользователь хранит свой пароль в тайне и сообщает автору, если учётной записью воспользовался кто-то другой. {% endblocktranslate %}
  • {% url 'accounts:data' as data_url %} {% blocktranslate trimmed with url=data_url %} Учётная запись удаляется в разделе «Персональные данные» после подтверждения паролем. Удаление учётной записи — отзыв согласия на обработку персональных данных. {% endblocktranslate %}

6. {% translate "Свои данные" %}

  • {% blocktranslate trimmed %} В разделе «Свои данные» можно загрузить таблицу со значениями по территориям России и смотреть её в тех же видах, что и данные сайта. Таблицу видит только загрузивший её; сайт её не публикует и никому не передаёт. {% endblocktranslate %}
  • {% blocktranslate trimmed %} Загружая таблицу, пользователь подтверждает, что вправе использовать её данные, и соблюдает условия их источника. Источник, названный при загрузке, указывается в документах и ссылках на расчёт вместе с пометкой «загружены пользователем». {% endblocktranslate %}
  • {% blocktranslate trimmed %} В таблицах не должно быть персональных данных — сведений о конкретных людях, а также сведений, доступ к которым ограничен законом. {% endblocktranslate %}
  • {% blocktranslate trimmed %} Таблицу или доску можно показать другому человеку закрытой ссылкой: по ней смотрят без входа и ничего не меняют. Ссылку создаёт и отзывает владелец, у неё есть срок; владелец сам решает, кому её передать, и отвечает за это. {% endblocktranslate %}

8. {% translate "Ограничение ответственности" %}

  • {% blocktranslate trimmed %} Предварительные значения помечены «предв.» и меняются, когда источник их уточняет. {% endblocktranslate %}
