8. {% translate "Кто видит данные" %}

{% blocktranslate trimmed %} Сохранённое, загруженные таблицы и доски видит только владелец. Таблицу или доску видит также тот, кому владелец передал закрытую ссылку на неё: только для чтения, пока не истёк срок ссылки и владелец её не отозвал; скачивать таблицу и документы — если владелец это разрешил. Читатель ссылки не видит ни учётной записи владельца, ни его других таблиц, кроме тех, ряды которых стоят на открытой доске. Администратор видит учётную запись — почту, имя, даты входа, число сохранённого и таблиц, — но не само сохранённое и не содержимое таблиц и досок. Обращения читают те, кто на них отвечает. {% endblocktranslate %}

9. {% translate "Загружаемые таблицы" %}

{% blocktranslate trimmed %} Таблицы раздела «Свои данные» предназначены для значений по территориям, а не для сведений о людях. Загружать таблицы с персональными данными нельзя. Содержимое таблиц сайт разбирает только для показа их владельцу: по нему не строятся выводы о пользователе, и оно не передаётся третьим лицам. {% endblocktranslate %}

{% blocktranslate trimmed with hours=guest_hours %} Таблица без учётной записи удаляется через {{ hours }} ч; после входа она переходит в учётную запись. Таблица удаляется на её странице, а все таблицы и доски — вместе с учётной записью; удаление затрагивает исходный файл, его версии и весь разбор. У таблицы хранятся последние версии файла (их число названо на странице таблицы); более старые удаляются при загрузке новой. Закрытая ссылка перестаёт действовать в свой срок, при отзыве и при удалении таблицы или доски. {% endblocktranslate %} {% if backup_days %} {% blocktranslate trimmed with days=backup_days %} Таблицы учётных записей входят в резервные копии и исчезают из них через {{ days }} суток после удаления; таблицы без учётной записи в копии не входят. {% endblocktranslate %} {% endif %}
