# Программный интерфейс RegionLens

**Базовый адрес:** `https://ДОМЕН/api/v1/`
**Описание:** `/api/docs/` (для человека), `/api/schema/` (OpenAPI 3.1),
`/api/docs/swagger/` (интерактивная оболочка)

---

## 1. Принципы

**Только чтение.** Интерфейс не изменяет данные.

**Данные открыты.** Все выборки доступны без ключа и без входа; ключей доступа нет.

**Адрес не зависит от языка интерфейса.** Точки данных обслуживаются без языкового
префикса: сохранённая клиентом ссылка не ломается при переключении языка в браузере.

**Версия в адресе.** Изменения, ломающие совместимость, выйдут под адресом `/api/v2/`.

---

## 2. Предел числа обращений

1 000 обращений в час с одного адреса (настройка `API_ANON_RATE`): хватает, чтобы
выгрузить несколько рядов целиком. При превышении — код 429 и поле `retry_after`
с числом секунд до снятия ограничения.

---

## 3. Точки данных

### 3.1 Территории

```
GET /api/v1/territories/
GET /api/v1/territories/RU-MOW/
```

Отборы: `level` (`country`, `federal_district`, `region`), `territory_type`,
`is_aggregate`. Территория адресуется кодом: ISO 3166-2 для субъектов, `FD-*` для
федеральных округов, `RU` для страны.

Уровень `region` включает две составные территории — Архангельскую и Тюменскую
области вместе с автономными округами. 85 субъектов без них —
`?level=region&is_aggregate=false`.

Поля: `code`, `slug`, `name_ru`, `name_en`, `abbreviation`, `level`, `territory_type`,
`district` (код округа), `is_aggregate`, `iso_code`, `okato`, `capital_ru`,
`capital_en`, `latitude`, `longitude`, `utc_offset`.

### 3.2 Показатели

```
GET /api/v1/indicators/?search=безработ
GET /api/v1/indicators/Y477110461/
```

Отборы: `section__slug`, `is_featured` (69 показателей основного набора), `polarity`
(`positive`, `negative`, `neutral`, `unknown`), `search` — по названию на двух языках
и коду, без учёта регистра и порядка слов. Показатель адресуется кодом источника
и приходит вместе с кратким описанием своих рядов (`series`).

### 3.3 Ряды наблюдений

```
GET /api/v1/series/?indicator__section__slug=naselenie
GET /api/v1/series/Y477110461:00/
```

Ряд — пара «показатель + разрез» и единица анализа: значения и рейтинги адресуются
ключом ряда вида `код:признак разреза`. Отборы: `is_analysis_ready` (ряд пригоден
для сравнительного анализа по покрытию), `has_subsection`, `indicator__section__slug`.

Поля: `key`, `slug`, `indicator`, `indicator_name_ru`, `section`, `name_ru`, `name_en`,
`has_subsection`, `unit`, `unit_short`, `polarity`, `first_year`, `last_year`,
`year_count`, `region_count`, `region_coverage`, `completeness`, `is_analysis_ready`,
`break_count`, `revision_count`.

### 3.4 Наблюдения

```
GET /api/v1/observations/?series=Y477110461:00&year_from=2023&year_to=2023
```

| Параметр | Обязателен | Значение |
|---|---|---|
| `series` | да | Ключ ряда |
| `territory` | нет | Код территории; без него — все субъекты (страна и округа исключены, чтобы не учитывать данные дважды) |
| `year_from`, `year_to` | нет | Границы периода |
| `limit`, `offset` | нет | Порция и смещение: по умолчанию 500 строк, не более 5 000 |

```json
{
  "count": 85,
  "limit": 2,
  "offset": 0,
  "results": [
    {
      "series_key": "Y477110461:00",
      "territory_code": "RU-AD",
      "year": 2023,
      "value": 500.6,
      "quality": "observed",
      "source": "dataset",
      "release": "2025",
      "flags": []
    }
  ]
}
```

**Пропуск возвращается значением `null` с признаком качества**, а не нулём
и не отсутствием записи. Признак: `observed` — наблюдение, `no_data` — нет данных
в источнике, `hidden` — значение скрыто источником, `not_applicable` — неприменимо.
Если по условиям нет ни одного наблюдения — 404.

Происхождение значения: `source` — `dataset` (набор «Если быть точным») или код
внешнего источника (`rosstat_bulletin`, `rosstat_grp`, `cbr`, `fns_sme`; см. 3.7),
`release` — год сборника или код выпуска источника, `flags` — признаки:
`preliminary` — предварительное, `computed` — рассчитано проектом (среднее месяцев,
отношение, сумма субъектов), `frozen_denominator` — на жителя по численности последнего
опубликованного года.

### 3.5 Рейтинги

```
GET /api/v1/rankings/?series=Y477110378:00&year=2023&order=desc
```

| Параметр | Обязателен | Значение |
|---|---|---|
| `series` | да | Ключ ряда |
| `year` | нет | Год; по умолчанию последний, за который есть рейтинг |
| `order` | нет | `desc` — от больших значений к меньшим (по умолчанию), `asc` — наоборот |

Рейтинг приходит целиком, без разбиения на страницы:

```json
{
  "series": "Y477110378:00",
  "year": 2023,
  "previous_year": 2022,
  "order": "desc",
  "count": 85,
  "results": [
    {
      "territory_code": "RU-CHU",
      "name_ru": "Чукотский автономный округ",
      "district_code": "FD-DFO",
      "value": 159070.9,
      "rank": 1,
      "previous_rank": 1,
      "percentile": 1.0,
      "ratio_to_country": 2.125
    }
  ]
}
```

### 3.6 Значения по месяцам

```
GET /api/v1/monthly/?series=RL_MORTGAGE_COUNT:00&territory=RU&kind=ytd&year_from=2026
```

Помесячный слой: зарплата, индекс цен, безработица и промышленность из бюллетеня
Росстата, ипотека и кредиты Банка России, малый и средний бизнес по реестру ФНС.
Ряд адресуется ключом годового ряда.

| Параметр | Обязателен | Значение |
|---|---|---|
| `series` | да | Ключ годового ряда |
| `territory` | нет | Код территории; без него — все субъекты |
| `kind` | нет | `level` — за месяц или на его конец, `ytd` — с начала года, `yoy` — к тому же периоду прошлого года; без него — все виды |
| `year_from`, `year_to` | нет | Границы периода |
| `limit`, `offset` | нет | Как у наблюдений |

Поля — как у наблюдения и ещё `month` (месяц, которым заканчивается период) и `kind`.

### 3.7 Источники и выпуски

```
GET /api/v1/sources/
GET /api/v1/sources/cbr/
GET /api/v1/releases/?source__code=fns_sme&status=parsed
```

Источник: `code`, названия, издатель и условия на двух языках, `page_url`, время
и исход последней проверки, `latest_release` — код последнего разобранного выпуска.
Выпуск: `source`, `code`, `title`, `reference_year`, `published_on`, `fetched_at`,
`url`, `sha256` (контрольная сумма файла в архиве), `size_bytes`, `status`
(`parsed`, `failed`, `fetched`), `parsed_at`, `row_count`. Выпуски — новые первыми,
по 50 на страницу.

## 4. Разбиение на страницы

Справочники (территории, показатели, ряды) — по 50 записей, `page_size` до 500:

```
GET /api/v1/indicators/?page=2&page_size=100
```

Ответ содержит `count`, `pages`, `next`, `previous` и `results`. Наблюдения выдаются
порциями со смещением (`limit`, `offset`, раздел 3.4), рейтинг — целиком.

## 5. Ошибки

| Код | `code` | Причина |
|---|---|---|
| 400 | `invalid` | Неверный параметр; поле `fields` называет параметр и причину |
| 404 | `not_found` | Объект не найден или по условиям нет наблюдений |
| 429 | `throttled` | Превышен предел числа обращений; `retry_after` — секунды до снятия |
| 503 | `warehouse_not_built` | Аналитический склад не собран |

```json
{
  "error": "Проверьте параметры запроса",
  "status": 400,
  "code": "invalid",
  "fields": {
    "year_from": ["Начало периода не может быть позже его конца"]
  }
}
```

Код ошибки — машиночитаемая строка: клиент различает случаи, не разбирая текст
сообщения, который к тому же переводится.

## 6. Примеры

Численность населения по всем субъектам за 2023 год:

```bash
curl "https://ДОМЕН/api/v1/observations/?series=Y477110461:00&year_from=2023&year_to=2023&limit=100"
```

Уровень безработицы в Москве за все годы:

```bash
curl "https://ДОМЕН/api/v1/observations/?series=Y477110418:00&territory=RU-MOW"
```

Рейтинг субъектов по средней зарплате:

```bash
curl "https://ДОМЕН/api/v1/rankings/?series=Y477110378:00&year=2023"
```

На Python:

```python
import requests

response = requests.get(
    "https://ДОМЕН/api/v1/observations/",
    params={"series": "Y477110461:00", "year_from": 2023, "year_to": 2023, "limit": 100},
    timeout=30,
)
response.raise_for_status()
for row in response.json()["results"]:
    print(row["territory_code"], row["value"], row["quality"])
```

## 7. Условия использования

Значения используются на условиях их источников — страница «Условия использования
и данные» (`/ru/terms/#api`). Источник каждого наблюдения называет поле `source`,
условия источников — `/api/v1/sources/` (поля `licence_ru`, `licence_en`). Значения
набора распространяются на условиях Creative Commons BY с атрибуцией:
«Социально-экономические показатели регионов России // Росстат; обработка: Если быть
точным, 2026».
Расчёты RegionLens (реальное выражение, сшивка, ряды на жителя) официальной статистикой
не являются.

Интерфейс рассчитан на выборки. Набор целиком доступен файлом по адресу источника.
