# Изменения

Записи — по выпускам, от новых к старым. Номер версии — «основная.дополнительная.исправление»:
0.9 — код заморожен перед итоговым замером распознавания своих таблиц, 1.0 — запуск
на рабочем стенде.

## 0.9.5 — 12.11.2026

Проверка перед размещением на открытом сервере: перегрузка, медленные запросы, права
контейнеров, цепочка поставки. «Свои данные» работают после входа. При выкладке: таблицы,
исследования и группы без владельца удаляет очистка по сроку; том базы, созданный раньше,
работает как прежде, роль без прав суперпользователя получает новый том
(docs/DEPLOYMENT.md, раздел 4); переменные `USERDATA_GUEST_*` из `.env` можно убрать.

### Добавлено

- Поверхность: общий предел обращений с одного адреса — `REQUESTS_PER_MINUTE`, 600
  в минуту; адрес IPv6 считается сетью /64. Отказ — ответ 429 до сборки страницы.
- Поверхность: предел тела запроса до его чтения — 1 МБ без входа, 34 МБ после входа;
  больше принимает только загрузка выпуска набора.
- Поверхность: адрес для сообщений об уязвимостях — `/.well-known/security.txt`.
- Кабинет: общий предел писем по действиям посетителей без входа — `PUBLIC_MAIL_PER_HOUR`.
- Развёртывание: две сети контейнеров (прокси с приложением и приложение с хранилищами
  без выхода наружу), контейнеры без лишних привилегий ядра, у прокси и Valkey файловая
  система только на чтение, пределы числа процессов.
- Развёртывание: приложение входит в PostgreSQL ролью без прав суперпользователя;
  предел времени запроса к базе; проверка удержанного соединения перед запросом.
- Развёртывание: число рабочих процессов — `WEB_CONCURRENCY`, по числу ядер; прежние
  секретные ключи при плановой смене — `DJANGO_SECRET_KEY_FALLBACKS`.
- CI: еженедельная проверка уязвимостей зависимостей и образов служб, анализ кода CodeQL;
  действия закреплены по коммиту, ключ репозитория у задач — только на чтение.
- Документация: подготовка сервера (вход по SSH, обновления, подкачка, IPv6), порядок
  действий при взломе, слои защиты от перегрузки.
- Проверки: пределы частоты и тела запроса, письма без входа, доступ гостя к «Своим
  данным».

### Изменено

- Свои данные: раздел работает после входа. Гостю страница раздела рассказывает о нём
  и предлагает войти; таблицы, исследования и группы регионов принадлежат учётной записи.
  Закрытая ссылка по-прежнему открывается без входа.
- Развёртывание: прокси принимает тело запроса целиком до передачи приложению, ограничивает
  время чтения заголовков и тела, при занятом приложении отвечает 503 сразу; память
  прокси — 512 МБ; готовые сжатые копии статики отдаются без сжатия на лету; `/readyz`
  снаружи закрыт.
- Развёртывание: образ собирается из последнего коммита, а не из рабочей папки; образы
  Caddy, PostgreSQL и Valkey запрашиваются у реестра при каждой выкладке.
- Кабинет: письмо восстановления пароля уходит вне запроса — по времени ответа не видно,
  зарегистрирован ли адрес; письмо подтверждения регистрации не несёт введённого имени.
- Поверхность: после пересборки склада прогреваются и страницы регионов.
- Кабинет: политика и условия — редакция 12.11.2026 (свои таблицы — после входа).

### Исправлено

- Поверхность: 16 соединений, присылающих тело запроса по байту, останавливали сайт —
  рабочие потоки ждали тело.
- Свои данные: без входа одна загрузка занимала на диске до 290 МБ, а предел считался
  только по адресу; исследования без входа создавались без предела.
- Развёртывание: под нагрузкой в сотни запросов в секунду прокси останавливался по памяти.
- Развёртывание: в образ мог попасть файл ключа из вложенного каталога рабочей папки:
  правила `.dockerignore` действовали только в корне.
- Развёртывание: `LOG_FORMAT` на рабочем стенде не действовал — журнал шёл в читаемом виде.
- Панель: адрес правки профиля пользователя отвечал ошибкой сервера на запрос GET.
- Поверхность: предел обращений к API считался по заголовку `X-Forwarded-For` как есть.

## 0.9.4 — 10.11.2026

Защита учётных записей и служебных меток, проверка сканером OWASP ZAP и испорченными файлами.
При выкладке применяется миграция учётных записей: уже заведённые записи считаются
подтверждёнными с даты создания.

### Добавлено

- Проверки: испорченные файлы в загрузку своих таблиц (пути наружу, пароль, бомбы
  в архиве и книге Excel, внешние сущности XML, незакрытая кавычка, перегруженная страница
  PDF), одновременный поиск, адрес возврата из формы, копия базы без схемы.
- Документация: проверка защищённости сканером OWASP ZAP и испорченными файлами, замер
  памяти стенда под нагрузкой.

### Изменено

- Кабинет: регистрация заканчивается переходом по ссылке из письма; до этого в запись
  войти нельзя. Страница отвечает одинаково свободному и занятому адресу, занятому уходит
  письмо-напоминание. Неподтверждённая запись удаляется через трое суток.
- Кабинет: браузер, из которого владелец уже входил, чужие неверные пароли не блокируют;
  блокировка по одной почте действует на остальных.
- Развёртывание: Django 6.1.3.
- Свои данные: книга XLSX и ODS проверяется до чтения по размеру и сжатию всех частей,
  а не только листов; страница PDF больше чем с 10 000 линий и знаков отклоняется до разбора
  (`USERDATA_PDF_PAGE_OBJECTS`, у сборников ведомств — до 2 646).

### Исправлено

- Свои данные: таблица с незакрытой кавычкой роняла страницу «Что в таблице» ошибкой
  сервера; теперь страница говорит, что разобрать не удалось, и называет причину.
- Свои данные: книга Excel в сотни килобайт с огромным списком общих строк принималась
  и разворачивалась в памяти сайта в сотни мегабайт.
- Свои данные: PDF с перегруженной страницей разбирался во время загрузки десятки секунд
  и занимал гигабайты памяти.
- Поверхность: поиск вопросом изредка отвечал ошибкой сервера при одновременных запросах.
- Поверхность: форма «В исследование» отвечала ошибкой сервера, если в поле адреса
  возврата подставить строку, которая не адрес; адрес возврата принимается, только если
  это путь на этом сайте.
- Сбор: путь от корня (`/…`) внутри архива выпуска отклоняется, как и путь с «..».
- Развёртывание: после выкладки, оборванной до миграций, следующая падала на резервной копии.
- Кабинет: выключение входа с кодом принимало неограниченное число неверных кодов;
  теперь — пять в час на учётную запись.
- Кабинет: ключ кодов входа во время настройки лежал в сеансе открытым; теперь зашифрован.
- Панель: метка закрытой ссылки на таблицу или исследование попадала в историю посещений
  и в журнал веб-сервера; в обоих она заменяется звёздочкой, как метки ссылок из писем.
- Кабинет: при недоступном Valkey пределы частоты (регистрация, восстановление пароля,
  ввод кода) переставали действовать; теперь счёт ведёт рабочий процесс.
- Сбор: архив выпуска, который разворачивается больше 2 ГБ, не распаковывается.
- Развёртывание: резервная копия, переименованная под другую отметку времени, не проходит
  проверку; проверка называет дату и возраст копии.

## 0.9.3 — 08.11.2026

Доступность по WCAG 2.2 AA, безопасность разбора своих таблиц и готовность к развёртыванию.

### Добавлено

- Доступность: шаг кода входа за две минуты до конца срока предупреждает, программа чтения
  это объявляет; кнопка «Продлить» отсчитывает срок заново, не больше десяти раз, набранные
  цифры остаются в поле.
- Доступность: форма, вернувшаяся с ошибками, ставит фокус на первое неверное поле.
- Доступность: подсказки поиска и окно быстрого перехода сообщают программе чтения строку,
  отмеченную стрелкой.
- Анализ: свежие расчёты (мимо кэша) с одного адреса ограничены — 300 за 10 минут
  (`ANALYTICS_COMPUTATIONS`); посчитанное открывается без ограничения.
- Проверки: сквозные проверки размера целей нажатия, фокуса под шапкой и под нижней полосой
  на телефоне, режима высокой контрастности и ширины 320 пикселей с увеличенными
  интервалами текста; разметка и цели
  в кабинете, панели и «Своих данных», цели — и в английской версии; контраст рамки поля
  и нижней ступени тёмной шкалы.
- Документация: защита персональных данных и криптография, обязанности оператора перед
  открытием сайта, доступность; политика безопасности репозитория; выпуски Росстата
  при первом наполнении стенда — из архива (на 08.11.2026 файлы Росстата отвечают
  сборщику 404).

### Изменено

- Оформление: рамки полей ввода контрастнее (3 : 1 к фону в обеих темах); нижние ступени
  шкалы карты в тёмной теме отделены от подложки и от «нет данных».
- Оформление: цели нажатия не меньше 24 пикселей — кнопка подсказки, ссылки в строках таблиц,
  ссылки подвала и строки пути, пункты оглавлений, раскрывающиеся заголовки, поле поиска
  во всю высоту рамки.
- Оформление: прилипшая шапка не закрывает элемент в фокусе; карточка региона на главной,
  подписи показателей анализа и название источника исследования больше не обрезаются при
  крупном шрифте и увеличенных интервалах.
- Оформление: в режиме высокой контрастности Windows видно кольцо фокуса в полях, образцы
  легенды карты сохраняют цвета.
- Оформление: подсказка графика не исчезает под указателем и закрывается клавишей Esc;
  предупреждения остаются на экране до закрытия, как ошибки.
- Кабинет: в журнале сервера неудачная попытка входа подписана отпечатком, а не почтой
  и адресом посетителя.
- Развёртывание: pandas 3.1, pyarrow 26, python-calamine 0.9, python-dateutil 4 и другие
  зависимости; разбор таблиц корпуса при этом не изменился.

### Исправлено

- Свои данные: имя столбца в файле Parquet могло дописать к запросу разбора свой текст и прочитать
  файлы сервера. Имена экранируются, а соединение разбора после чтения файла теряет доступ
  к файлам и сети.
- Свои данные: таблица Parquet со столбцом «v» не разбиралась.
- Свои данные: подделка документа Word с объявлением сущностей в кодировке UTF-16 проходила
  проверку; объявления теперь ищет сам парсер, в любой кодировке.
- Свои данные: срок в единице измерения («на конец года, штук», «в среднем за год») больше
  не принимается за единицу «годы».
- Развёртывание: таблицы, загруженные на машине разработчика, попадали в образ и оттуда —
  в хранилище стенда; служба разборов на новом стенде не могла писать в свой том.
- Склад: первая сборка на новом стенде присылала администраторам ложное письмо о пропавших
  рядах Банка России и ФНС, которые появляются только с первым сбором выпусков.
- Кабинет: в «Настройках» подписи полей «Текущий пароль» всех форм вели к первому полю.
- Оформление: на телефоне полоса вызова панели параметров закрывала элемент в фокусе.
- Развёртывание: `main.py` падал, если его вывод перенаправить в файл.
- Панель и сравнение: таблицы без подписи и без заголовков строк.
- Поверхность: после кнопок «Назад» и «Вперёд» поля выбора и кнопки сохранения графика
  удваивались; возврат на адрес, открытый без перезагрузки, мог показать страницу без шапки
  и оформления.
- О проекте: тема работы — «Веб-приложение…», как в README.

## 0.9.2 — 30.10.2026

Поиск вопросом, сверка расчётов с библиотеками, сверка склада с публикацией Росстата
и поправки к исходному набору.

### Добавлено

- Поиск: опечатка в названии места и в служебных словах («нижегроодская область», «рейтинг
  регоинов»), падежи названий, которые не узнавались («в Адыгее», «население Алтая»).
- Поиск: «уровень жизни» и «благосостояние» — общие вопросы, поиск предлагает интегральный
  индекс.
- Поиск: «покажи», «подскажите», «по региону», «российских регионов», «в области» не мешают
  понять вопрос.
- Проверки: индекс Морана и локальные индексы сверены с esda (PySAL), регрессия с обычными
  и устойчивыми ошибками — со statsmodels, веса CRITIC и энтропии и TOPSIS — с pymcdm. Ответы
  библиотек лежат в проверках, в зависимости проекта библиотеки не входят.
- Проверки: формулы нормировки, свёртки индекса, весов, классов карты и сближения — на значениях,
  посчитанных вручную.

### Изменено

- Поиск: ответ числами — только если в показателе нашлись все содержательные слова вопроса.
  «Население Китая», «плотность населения», «пособие по безработице» больше не получают чужой
  показатель: поиск показывает ближайшее без уверенного ответа.
- Поиск: опечатка — одна правка в слове, а не похожее слово: «доставка» не «ставка», «гороскоп»
  не «городской», «экологический» не «экономический».
- Поиск: слова степени — «высокая», «крупные», «лидеры», «быстрее» — признак рейтинга, а не
  слова показателя.
- Поиск: если слова запроса нашлись только в длинном официальном названии ряда, сначала
  смотрится полный перечень: «прожиточный минимум» ведёт к ряду о прожиточном минимуме, а не
  к уровню бедности.
- Поиск: разрез показателя («Прочие выплаты») не отвечает на одно слово.
- Выгрузка: PDF печатает значения с точностью показателя, как страницы сайта, а не всегда
  с двумя знаками после запятой.

### Исправлено

- Данные: 53 значения шести рядов с доказанными ошибками исходного набора исправлены при сборке
  склада (`data/reference/source_corrections.json`) и отмечены на сайте и в API. Поправка
  применяется, только пока в наборе стоит ошибочное значение.
- Перевод: пояснения к расчётам анализа на английской версии выходили по-русски; добавлены
  английские названия 113 разрезов рядов.
- Поиск: «за 2023 год» — год, а не срок: ответ значением, а не динамикой.
- Поиск: «Sakhalin» больше не принимается за Саху: среди написаний одной длины точное
  совпадение проверяется раньше совпадения по началу слова.
- Поиск: ряды, непригодные к сравнению регионов, больше не вытесняют пригодные из отбора
  по полному перечню.
- Поиск: «что такое коэффициент корреляции» находит этот термин: слово связи в вопросе
  о термине — часть термина.
- Поиск: на вопрос «почему» показывается ближайший показатель, даже если нашлись не все слова.

  таблицы не берётся из базы «к I кварталу 2025» — раньше таблица молча собиралась
  не за тот год, теперь мастер спрашивает год.
- Свои данные: справочные столбцы и столбцы без названия не считаются показателями,
  когда год есть только у части столбцов.
- Свои данные: большой документ Word старого вида (DOC) — совет сохранить его как DOCX,
  а не «не читается как таблица Excel»; книга Excel с вложенным документом Word — книга.
- Зависимости: filelock 4.2.1, msgpack 1.2.3.
