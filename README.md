# RegionLens

Веб-приложение для анализа и визуализации социально-экономических показателей регионов
Российской Федерации.

**Автор:** Кузьмин Евгений Олегович · студенческий билет ГМФИТД0401/25-вос
**Тема выпускной квалификационной работы:** «Приложение для анализа и визуализации
социально-экономических показателей регионов РФ»

---

## Что умеет

- **Найти показатель** среди 1 294 наименований: основной набор по темам с короткими
  названиями, полный перечень с отборами и поиском, исправляющим опечатки.
- **Показать, что ряд нельзя сравнивать во времени:** 833 разрыва сопоставимости,
  найденных в методических примечаниях источника, отмечены прямо на графиках.
- **Показать пересмотры:** все версии наблюдения по выпускам изданий хранятся,
  инструмент «Пересмотры статистики» показывает расхождения.
- **Продолжать ряды после последнего года набора:** выпуски бюллетеня Росстата и таблицы ВРП
  собираются автоматически, хранятся в архиве как получены и сверяются с набором
  за общие годы; предварительные и рассчитанные значения помечены.
- **Показать, что происходит сейчас:** ипотека, кредиты и малый бизнес по данным Банка
  России и реестра МСП ФНС, зарплата, цены и безработица — по месяцам; «Что сейчас»
  в паспорте региона и помесячный блок на странице показателя.
- **Отличить пропуск от нуля:** «нет данных», «значение скрыто» и «неприменимо»
  различаются везде, от графика до выгрузки.
- **Ответить о регионе понятным языком:** паспорт региона — главное, сильные и слабые
  стороны по основному набору, похожие регионы.
- **Исследовать:** рабочая поверхность — карта, динамика, рейтинг, распределение
  и таблица одного выбора; шесть инструментов анализа (неравенство, конвергенция,
  корреляции, пространственная автокорреляция, интегральный индекс, пересмотры).
- **Сохранить и поделиться:** любое состояние экрана — ссылка; сохранённый вид хранит
  параметры, а не числа, и открывается на текущих данных; готовая ссылка для цитирования.
- **Выгрузить:** таблица значений, паспорт региона и рейтинг — в CSV, XLSX и PDF;
  открытый интерфейс REST без ключей.
- **Открыть свою таблицу на той же карте:** CSV, Excel, ODS, Parquet, архив ZIP или вставка
  из Word; форма таблицы, годы и периоды, разрезы и регионы узнаются сами, область
  с автономными округами и абсолютные величины отмечены, суммы пересчитываются на жителя.
  На своих рядах работают инструменты анализа; пересчёты в цены года, к России, к прошлому
  году и в доли, формулы из рядов своих таблиц и рядов сайта, вид по месяцам, первый
  взгляд на таблицу и связи с основными показателями. Таблицу видит только владелец; без
  входа она хранится сутки.

## Источник данных

«Социально-экономические показатели регионов России» // Росстат; обработка: «Если быть точным»,
2026. URL: <https://tochno.st/datasets/regions_collection>. Лицензия — Creative Commons BY.

Версия набора `v20260313`: 1 969 010 строк исходной выгрузки, 1 294 показателя, 2 952 ряда,
85 субъектов, 8 федеральных округов, 19 статистических изданий в 38 выпусках, 2001–2025
годы. После разрешения повторов между выпусками в складе 1 912 559 наблюдений.

Набор обновляется по мере выхода версий: новую версию на сайте «Если быть точным» ежедневный
сбор источников скачивает и проверяет сборкой рядом с рабочим складом, а администратор
принимает её в панели по отчёту о различиях.
После последнего года набора двадцать рядов продолжаются по изданиям Росстата: ежемесячному бюллетеню «Информация для ведения мониторинга
социально-экономического положения субъектов Российской Федерации» и таблице «Валовой
региональный продукт по субъектам Российской Федерации». Ряды тем «Кредиты» и «Малый
бизнес» строятся по сервису получения данных Банка России (открытые данные, со ссылкой
на источник) и статистике Единого реестра субъектов МСП ФНС России. Перечень, выпуски
и итог сверки — на странице «Источники данных» (`/datasets/sources/`); условия каждого
источника и правила интерфейса — на странице «Условия использования» (`/terms/`),
хранимые сведения о пользователях — в «Политике обработки персональных данных»
(`/privacy/`).

## Технологии

| Слой | Решение |

| Хранение | PostgreSQL 18 (приложение), DuckDB (аналитический склад, звёздная схема), Valkey 8 (кэш) |

Назначение каждой библиотеки — комментарием рядом с ней в `pyproject.toml`.

## Быстрый старт

Нужны Python 3.14, [uv](https://docs.astral.sh/uv/) и Docker (для PostgreSQL и Valkey).

```powershell
uv sync
docker compose -f docker/compose.dev.yml up -d
# положите data_regions_collection_102_v20260313.parquet в data/raw/
uv run python main.py --setup
uv run python main.py
```

`main.py --setup` создаёт `.env` со свежим ключом, применяет миграции, загружает
справочник территорий, собирает склад, наполняет тексты и собирает переводы; повторный
запуск доводит подготовку до конца, ничего не ломая. `main.py --check` называет,
чего не хватает окружению, не запуская сервер.

Приложение — <http://127.0.0.1:8000/>. Панель отладки Django включается строкой
`DEBUG_TOOLBAR=True` в `.env`.

## Команды управления

| Команда | Назначение |
|---|---|
| `python manage.py seed_reference` | Загрузка справочника территорий с проверкой целостности (`--check` — только проверка) |
| `python manage.py etl_build --full` | Полная сборка аналитического склада |
| `python manage.py etl_build --marts` | Пересчёт витрин без перезагрузки наблюдений |
| `python manage.py etl_build --check` | Профиль исходного файла без записи |
| `python manage.py seed_content`, `seed_content_en` | Тексты методики и глоссария на двух языках |
| `python manage.py seed_catalog_names` | Английские названия разделов, показателей, разрезов, единиц, изданий и переводы примечаний (`--check` — перечень непереведённого) |
| `python manage.py build_boundaries` | Подготовка границ субъектов для карты (`--input FILE` — из скачанного файла) |
| `python manage.py record_backup` | Отметка о снятой резервной копии для панели (вызывает `scripts/backup.sh`) |
| `python manage.py collect --all` | Сбор выпусков источников: в архив, разбор, пересборка склада; с `--due` и `--all` — ещё и проверка новой версии набора (`--due` — кому пора, `--url`, `--file`, `--reparse`, `--no-build`, `--verify`) |
| `python manage.py visits` | Статистика посещений по журналу Caddy (GoAccess из образа; на стенде — таймер раз в час) |
| `python manage.py prune_personal_data` | Удаление персональных данных по сроку из политики обработки (на стенде — таймер раз в сутки) |
| `python manage.py reset_two_factor ПОЧТА` | Выключить вход с кодом у учётной записи, потерявшей телефон и резервные коды |
| `python manage.py userdata_build ВЕРСИЯ extract\|build` | Разбор большой таблицы своих данных отдельным процессом (запускается со страницы мастера) |
| `python manage.py userdata_guest_dirs` | Каталоги таблиц без учётной записи — для исключения из резервной копии |
| `python scripts/userdata_corpus.py check\|files\|tables\|build` | Замер распознавания и пути до карты на корпусе настоящих файлов (корпус — вне репозитория) |
| `python scripts/i18n_tools.py extract --locale en` | Обновление каталога перевода интерфейса |
| `python scripts/i18n_tools.py compile` | Сборка двоичного каталога перевода |

Новый выпуск набора загружается и из панели управления («Загрузка данных»): файл
проверяется сборкой рядом с рабочим складом и отчётом о различиях, а после решения
администратора склад собирается из него отдельным процессом (`etl_build --run`); ход
сборки виден на карточке запуска. Одновременно идёт не больше одной сборки.

Сборка склада требует исключительного доступа к файлу DuckDB. В Windows запущенный
сервер разработки держит файл открытым, и сборка завершится сообщением «файл занят
другим процессом» — остановите сервер на время сборки. На Linux новый склад подменяет
прежний и при работающем сервере.

## Доступ

Гостю открыто всё публичное: данные, анализ, методика, выгрузка документов
(`/documents/`) и интерфейс REST (`/api/v1/`, описание — `/api/docs/`, предел —
1 000 обращений в час с адреса), «Мой регион» — в cookie. Пользователю — личный
кабинет: обзор (мой регион, новое по сохранённому, последние виды), «Сохранённое»
(регионы и показатели с пометками, виды экрана), свои обращения с ответами, профиль,
безопасность (смена пароля и почты, выход на других устройствах, вход с одноразовым
кодом) и персональные данные (выгрузка JSON, удаление учётной записи). Свои таблицы
(`/ru/own-data/`) загружает и гость — до трёх на сутки; после входа они переходят
в учётную запись. Панель управления
`/manage/` открыта по ролям: «Администратор» — целиком (состояние служб, пользователи
и роли, загрузка данных и замечания проверок, источники, обращения, тексты методики
и глоссария, посещения), «Редактор содержимого» — тексты, обращения и посещения; с любой
ролью панели вход требует одноразового кода. Об ошибке 500 администратор узнаёт письмом
(`DJANGO_ADMINS`, одна и та же ошибка — не чаще раза в час), как и о неразобранном выпуске
источника, недоступном источнике и неудачной сборке склада по таймеру.

## Разработка

```powershell
uv run ruff check . ; uv run ruff format --check .   # линтер и форматирование
uv run mypy apps config                              # статическая типизация
uv run pytest -m "not slow and not e2e"              # быстрый прогон
uv run pytest                                        # всё, кроме сквозных
uv run pytest -m e2e                                 # сквозные браузерные сценарии
uv run playwright install chromium                   # браузер для сквозных
```

Те же операции собраны в `Makefile` (`make help`); CI выполняет те же команды.
